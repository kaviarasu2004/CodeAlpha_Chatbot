# CodeAlpha_Chatbot

A simple rule-based chatbot built in Python as part of the CodeAlpha Python Programming Internship.

## Overview

The chatbot matches keywords in user input against a predefined set of responses and replies accordingly. It runs entirely in the console and requires no external libraries or APIs.

## Features

- Responds to common greetings and phrases (`hello`, `hi`, `how are you`, `bye`, etc.)
- Randomized replies for a more natural feel
- Simple keyword-matching logic using `if-elif` style dictionary lookups
- Graceful exit on `bye`, `exit`, or `quit`

## Concepts Used

- Functions
- Loops (`while`)
- Conditional matching (`if-elif`)
- Dictionaries
- Basic input/output

## How to Run

1. Make sure Python 3 is installed.
2. Clone this repository:
   ```bash
   git clone https://github.com/kaviarasu2004/CodeAlpha_Chatbot.git
   cd CodeAlpha_Chatbot
   ```
3. Run the script:
   ```bash
   python chatbot.py
   ```
4. Chat with the bot in the console. Type `bye`, `exit`, or `quit` to end the conversation.

## Example

```
Chatbot: Hi! Type 'bye' to end the conversation.

You: hello
Chatbot: Hi!
You: how are you
Chatbot: I'm fine, thanks! How about you?
You: bye
Chatbot: Goodbye!
```
